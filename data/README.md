# Data Map

`data/` contains derived corpus text used by downstream scripts.

## Contents
- `chapters/`: one plain-text file per parsed chapter

## Source Of Truth
- The original corpus is `HongLouMeng.txt`.
- `data/chapters/` is generated by `src/parse_chapters.py`.

## Practical Rule
- If parsing logic changes, regenerate `data/chapters/` instead of editing chapter files by hand.
